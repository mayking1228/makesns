# GitHub 분리 보관 · 2026-11-01

MakeSNS는 EnterCrews CRM과 독립된 프로젝트로 보관한다. Node 24, pnpm 11.19.0에서 검증한다. Next.js 정적 사이트와 전용 단축링크 서비스의 소스·테스트·로컬 자산·다국어 문구·라이선스·배포 설치기만 포함한다. CRM 코드·DB·인증키를 포함하지 않는다.

## 포함 범위

8개 언어(en/ko/ja/es/ms/pt-BR/id/tr), 프로필 편집과 현지 템플릿, 줄바꿈, 글자 스타일 26종·장식 48종·문자 1,596개, 즐겨찾기·최근 복사·문자 모으기, 이미지 도구·원형 크롭·릴스 커버, QR, 독립 단축링크, 동의 기반 GA4, 다국어 SEO·대표 이미지·국기를 포함한다.

`yüz yuz`와 같은 검색용 별칭이 화면 라벨에 노출되지 않는 수정본이다. scripts/check-site-labels.py는 빌드된 8개 언어의 홈/문자/프로필 총 24개 화면을 검사한다. 숨겨진 검색 별칭 자체는 검색 편의를 위해 유지한다.

GitHub에 올린 코드와 실제 운영 배포 상태는 별개다. 최근 운영 점검에서 라벨이 잘못된 이전 release가 제공되는 것이 확인되었고, 이를 교체할 별도 v2 배포 파일이 준비되어 있다. 이 저장소 업로드가 운영 반영을 실행하지 않는다.

## 검증과 CI

`pnpm typecheck`, `pnpm test`, `pnpm build`, `python3 scripts/check-site-labels.py out`.

GitHub push/PR/수동 실행은 위 검사를 수행한다. 운영 키가 필요 없고, 워크플로는 contents: read 권한만 가진다. GitHub 실행 성공은 로컬 성공과 별도로 확인한다.

## 제외와 보존

.env, node_modules, .next, out, 실행 로그, SQLite/DB 백업, ip-salt, 서버 비밀 설정, 배포 압축파일을 Git에 저장하지 않는다. 네이버 소유확인 값과 GA 측정 ID는 페이지의 공개 설정이며 비밀키가 아니다. 단축링크 실데이터와 관리키는 서버 자료이므로 소스 저장소로 복사하지 않는다. 링크의 소실을 막으려면 운영 /var/lib/makesns-links를 별도로 백업한다.

자동 배포에는 별도 서버 권한 연결이 필요하다. 정적 사이트의 /opt/makesns/current와 단축링크 서비스 /opt/makesns-links/current는 서로 다른 대상이다. 프런트 수정 때 단축링크 서비스·CRM·Nginx·인증서를 불필요하게 재시작하거나 변경하지 않는다. 개발/운영을 분리하고 운영 배포는 백업·검사·실패 시 이전 release 복구를 수행한다.

## 初回ローカル検証 / 초기 로컬 검증

타입 검사, 테스트 88/88, 프로덕션 정적 빌드, 113개 페이지 SEO, 언어별 대표 이미지 9종, 24개 화면의 잘못된 라벨 비노출 검사가 통과했다. 이 결과가 GitHub Actions의 실행 성공 또는 운영 반영 완료를 의미하지는 않는다.
