## Google 검색에서 확인할 것

기존 makesns.com Search Console 속성을 그대로 사용한다. 배포 후 sitemap.xml의 정상 상태를 확인하고 /id/, /id/caption/, /id/fonts/, /id/profile/을 URL 검사한다. 별도 언어 속성을 새로 만들 필요는 없다.

우선 검증할 검색어는 `spasi kosong`, `font keren Instagram`, `bio Instagram`, `simbol aesthetic`, `foto profil bulat`, `sampul Reels`다. 실제 검색량을 확인한 수치가 아니라 검색 의도 가설이며, 페이지에 키워드를 반복 삽입하지 않는다.

국가 인도네시아 + 페이지 /id/ 필터로 노출·클릭·CTR·검색어를 주 단위로 본다. GA4에서는 동의한 사용자의 ui_language=id와 도구별 복사·다운로드·프로필 완성을 비교한다. 입력 문장·이메일·파일·사용자가 단축하는 원본 주소는 이벤트에 넣지 않는다. 4~8주 자료를 보고 콘텐츠와 제목을 조정하며 색인·순위 상승을 보장하지 않는다.

세부 SEO 운영 기준은 SEO-PT-BR-2026-11-01.md의 공통 기술·콘텐츠·측정 원칙을 따른다. 인도네시아어 페이지에는 해당 시장의 예시를 적용하고 브라질 문구를 재사용하지 않는다.

## 배포 범위

좁은 모바일 화면에서 긴 단어가 가로 폭을 늘리지 않도록 제목 크기와 줄바꿈을 보완했다. 400px 이하에서는 소개글 정렬 버튼을 별도 행으로 배치해 기존 언어에서도 잘리지 않도록 했다.
