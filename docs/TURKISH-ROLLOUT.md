# 터키어 및 언어별 국기 표시

2026-11-01 · 운영 반영 전 검토본

## 적용 범위

- 터키어 /tr/, HTML·hreflang tr, 공유 메타 tr_TR.
- 전체 도구·사용 예시·개인정보 안내 14개 페이지, 독립적인 프로필 13종, 문구 519개.
- İstanbul, İzmir, Ankara, Bursa, Eskişehir의 일상·학생·창작자·가게·회사 계정을 위한 가상 예시.
- Kopyala(복사), İndir(다운로드), biyografi(소개글), şekilli yazı(꾸미기 글꼴), Reels kapağı(릴스 커버) 등 터키어 용어 적용.
- 문장과 이름의 ı·İ·ş·ğ·ç·ö·ü는 글꼴 변환에서도 보존한다. 지원 범위는 A–Z와 일부 숫자이며 터키어의 모든 글자를 변환한다고 안내하지 않는다.
- 검색에서만 대소문자·발음 구별 기호·점 없는 ı를 정규화한다. 예: ŞEKİLLİ YAZI와 sekilli yazi, ÇİÇEK와 cicek.
- 사용자 초안·직접 입력한 이름·즐겨찾기·단축주소 보존. 언어 변경 시 미편집 기본 예시만 현지화.

## 언어 선택 국기

현재 언어 표시, 언어 선택 팝업, 중립 홈페이지 언어 카드에 국기와 언어명을 함께 표시한다. 국기만으로 언어를 구분하지 않으며 스크린 리더는 중복 국기를 읽지 않는다. 중립 홈페이지 상단은 지구본을 유지한다.

영어 미국 / 한국어 대한민국 / 일본어 일본 / 스페인어 스페인 / 말레이어 말레이시아 / 브라질 포르투갈어 브라질 / 인도네시아어 인도네시아 / 터키어 튀르키예.

운영체제에 따라 이모지 국기가 글자로 보이는 문제를 피하기 위해 로컬 SVG를 사용한다. 외부 이미지 서비스에 요청하지 않는다. flag-icons v7.5.0의 MIT 라이선스 원문은 public/flags/LICENSE.txt에 보관한다.

## 검색 및 측정

사이트맵은 총 113개 페이지, 실제 존재하는 8개 언어 사이의 상호 hreflang과 각 페이지의 자기 canonical을 사용한다. /tr/은 별도 속성을 만들지 않고 기존 makesns.com Search Console 속성에서 관리한다.

배포 후 /tr/, /tr/fonts/, /tr/profile/, /tr/caption/의 색인 상태와 sitemap.xml을 확인한다. 검증할 검색어 가설은 şekilli yazı, Instagram biyografi örnekleri, görünmez boşluk, kopyala yapıştır semboller, yuvarlak profil fotoğrafı, Reels kapağı다. 실제 검색량을 조사한 수치는 아니며 색인·순위 상승을 보장하지 않는다.

국가 Türkiye와 페이지 /tr/ 필터로 노출·클릭·검색어를 관찰한다. GA4는 동의 후에만 작동하며 ui_language=tr과 도구별 완료 이벤트를 기록한다. 사용자 이름·문장·이메일·파일·원본 단축 URL은 보내지 않는다.

## 배포

MakeSNS 정적 파일과 단축링크 전용 서비스 표시 문구를 갱신한다. 기존 CRM 코드·PM2·CRM DB·Google 인증·인증서는 변경하지 않는다. 두 서비스가 공유하는 서버·Nginx의 상태를 읽기 전용으로 확인하고, 기존 MakeSNS 관리 설정만 갱신한다. 실패 시 MakeSNS의 이전 사이트와 전용 서비스 설정을 복구한다. 이전 릴리스와 링크 저장 자료는 보존한다.

CRM 보호 검사: 배포 전 https://entercrews.net/login이 HTTP 200인지 루프백 경로로 확인한다. 정상이 아니면 MakeSNS 설정 변경 전에 중단한다. 배포 후에도 같은 응답을 확인하며, 실패하면 MakeSNS 변경을 복구한다. CRM 자체를 재시작하거나 수정하지 않는다.
