# Gallery navigation and image-task placement

Template selector, current title, counter and alignment controls are grouped immediately above the comparison. Previous/next buttons sit inside the comparison frame; title captions on both cards track the selection. Explanatory accents are in an optional details section below the comparison, keeping the primary browse/load/copy path compact. Template browsing does not alter personal drafts.

The resizer page now has Resize & fit and Circular profile photo tasks. The same photo cropper used by the profile editor is loaded on demand. Switching tasks preserves the separate in-page image work. In resizer context, the profile-avatar apply button is omitted; it remains available in profile context. Existing size, format, ZIP, privacy and upload constraints are retained.

No routing, data migration, analytics contract, CRM, Nginx or PM2 changes.
