# 글자 스타일·장식·특수문자 라이브러리 확장

2026-11-01 · 운영 반영 전

## 자료와 선택 방식

- 글자 스타일·문자 변환 26종: 기존 18종 유지, 작은 대문자·위첨자·아래첨자·괄호 문자·영문 대소문자·숫자 전용 변환 추가.
- 텍스트 장식 48종: 프레임 24, 글자 장식 12, 글꼴과 프레임 조합 12. 조합을 독립적인 새 글꼴이라고 세지 않는다.
- 문자 1,596개, 세부 분류 45개. 기호·얼굴문자·이모지·꾸미기 조합·구분선으로 먼저 나눈다.
- 얼굴문자는 인사·포옹·윙크·사과·달리기·잠·어깨 으쓱·응원·사랑·고양이·기쁨·슬픔 등을 구분한다.
- Emoji 16.0 완전한 시퀀스와 CLDR 이름·검색어를 사용한다. 피부색 변형 수천 개를 반복 나열하지 않고 주요 주제를 골랐다. 최신 Emoji 전체라고 주장하지 않는다.
- 한국어·영어·일본어·스페인어·말레이어·브라질 포르투갈어·인도네시아어·터키어의 UI와 문자 검색 이름을 제공한다.
- 추천순은 편집된 순서이며 인기 통계를 의미하지 않는다. 신규순은 이번에 추가한 항목을 먼저 표시한다.

## 사용 흐름

1. 글자 스타일은 이름·문장을 한 번 입력하고 여러 스타일로 비교한다. 첫 12개를 표시하고 더 보기로 확장한다.
2. 텍스트 장식은 별도 탭에서 선택한다. 프레임·글자 장식·글꼴 조합과 분위기를 선택할 수 있다. 현재 입력에서 결과가 같은 장식은 기본 목록에서 중복 표시하지 않는다. 저장한 즐겨찾기는 ID별로 유지한다.
3. 특수문자는 검색과 큰 종류를 먼저 제공한다. 세부 종류는 그 범위 안에서 고른다. 분위기·정렬 같은 부가 필터는 접어서 연다.
4. 문자 페이지의 기본 클릭은 복사한다. 별표는 저장만 하며 복사를 일으키지 않는다.
5. 문자 모으기 모드는 커서 위치에 문자를 모아 수정하고 되돌리기·전체 복사할 수 있다. 최대 500 UTF-16 단위이며 이모지를 중간에서 잘라 추가하지 않는다.
6. 프로필 내부 선택 화면에서는 클릭한 문자를 현재 소개글의 커서 위치에 삽입한다. 글꼴·장식은 이름에 적용할 수 있다. 별도 페이지에서 장식 문구를 소개글로 보낼 수도 있다.
7. 프로필로 보내는 500단위 전송 한도를 넘는 결과는 적용 버튼을 비활성화해 조용히 잘라 보내지 않는다. 복사는 전체 결과를 유지한다.

## 보존·개인정보·성능

- 기존 글꼴·문자의 ID와 localStorage 키/version을 유지한다. 새 decorations 필드를 선택적으로 읽으며 예전 데이터는 빈 목록으로 보완한다.
- 즐겨찾기는 모든 글자 스타일, 장식 100개, 문자 300개를 지원하고 최근 사용은 기존 24개를 유지한다.
- 모은 문장은 이 페이지 메모리에만 존재한다. 서버에 보내거나 사용 통계에 포함하지 않는다.
- GA4는 동의 후 기존 고정 이벤트만 사용한다. 입력·파일·클립보드·모은 문장을 이벤트에 넣지 않는다.
- 처음에는 문자 48개·스타일 12개만 그린다. 프로필의 선택 도구는 필요할 때 불러온다. 즐겨찾기 검증은 가벼운 ID 목록을 사용하여 전체 다국어 문자 설명을 홈에서 불러오지 않는다.
- 한글·일본어·터키어 특수문자 등 지원하지 않는 글자는 원문을 유지한다. 결합 장식은 글꼴 자체의 교체가 아니다. 운영체제·앱에 따라 표시와 글자 수 계산이 다를 수 있다.

## 자료 출처

Unicode 데이터 라이선스는 public/licenses/UNICODE-LICENSE.txt에 동봉한다. Emoji 16.0 및 CLDR 자료 주소·받은 파일 해시는 LIBRARY-DATA-SOURCES.json에 기록한다. 사용자 참고 문서는 얼굴문자·장식 종류를 선정하는 데 참고했으며 문서 안의 프로그램을 실행하지 않았다.

## 배포

정적 사이트 파일만 교체한다. Nginx·CRM·DB·단축링크 서비스·Google 인증·인증서는 수정하거나 재시작하지 않는다. 기존 국가별 페이지·국기·SEO·제목 크기 수정이 포함된다. CRM 로그인의 배포 전후 HTTP 200을 읽기 전용으로 확인한다. 페이지·CSS·CRM 검사 실패 시 이전 MakeSNS 사이트로 복구하며 이전 릴리스는 보존한다.
