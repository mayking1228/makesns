# MakeSNS SEO 점검·보강

범위: 정적 공개 페이지 37개. 360photo.kr·aiphotobooth.kr의 워드프레스 메타데이터나 Search Console 원격 설정을 변경한 작업은 아닙니다.

## 반영

- 각 언어의 도구 목적이 드러나는 고유 제목·설명. 글씨체/영어 글씨체, 줄바꿈/공백, 특수문자/얼굴문자/이모지, 원형 프로필 사진, 릴스 커버 등 실제 기능을 검색 의도와 연결했습니다. 영어·일본어 키워드는 직접 번역 대신 해당 도구의 자연스러운 이름을 사용했습니다. 검색량·경쟁도·실시간 순위를 조회한 결과는 아닙니다.
- HTML lang, canonical, 한영일 alternate 및 x-default 일치. 홈 x-default는 언어 선택 페이지 /, 각 도구의 기본 대체 페이지는 영어 동일 경로입니다. 사이트맵의 alternate도 같은 기준으로 통일했습니다.
- OG 및 X 제목·설명·이미지·대체 텍스트·언어/대체 언어. 개인정보 페이지와 릴스 커버에도 동일한 기준을 적용했습니다.
- 정적 HTML에 WebSite·WebPage JSON-LD를 출력하고, 실제 도구에는 무료 WebApplication 정보를 추가했습니다. 하위 페이지 BreadcrumbList는 2개 이상 항목을 사용합니다. 허위 평점·리뷰·법인 정보·브랜드 sameAs·작동하지 않는 SearchAction은 만들지 않았습니다.
- 404 noindex, robots.txt, 사이트맵, 1200×630 공유 이미지, Naver 인증 태그 유지. 쿼리·해시·개인 입력 내용은 canonical/구조화 데이터에 포함하지 않습니다. Google Analytics는 동의 후에만 연결됩니다.

meta keywords는 Google 웹 검색 순위에 사용되지 않으므로 키워드를 늘어놓는 태그를 추가하지 않았습니다. 제목·설명·H1·본문·실제 사용법에서 검색 의도를 드러내도록 편집했습니다. 구조화 데이터가 없었다고 기존 페이지가 색인되지 않는다는 뜻은 아니며, 새 데이터가 리치 결과나 순위 상승을 보장하는 것도 아닙니다. 사이트맵의 무의미한 매일 lastmod 갱신도 추가하지 않았습니다.

## 점검 결과

보강 전: og:locale 7개 페이지 누락, 개인정보 페이지 3개의 공유 메타 누락, 홈 3개의 x-default 불일치, 구조화 데이터 미제공 28개 페이지(보강 대상).
보강 후: 설정한 점검 항목 기준 37개 페이지 모두 통과. 제목·설명 중복 없음. 별도 전용 검사에서 HTML head, canonical·sitemap alternate 일치, 단일 JSON-LD, 실제 도구 18개 언어별 애플리케이션, robots·404·이미지 치수를 확인합니다.

실시간 검색 노출·클릭률·Search Console 색인 상태는 조회하지 않았습니다. 배포 후 URL 검사로 실제 Google/Naver 읽기 결과를 확인할 수 있습니다.

## 배포 복구

apex/www 두 Nginx CSP가 있는 실제 운영 구조를 반영했습니다. 모든 관리 대상 CSP에 media-src self/blob만 보완하며 나머지 Google Analytics·보안 정책은 유지합니다. Nginx·페이지 검사 실패 시 설정과 사이트를 함께 복구합니다. CRM·PM2·DB·인증서는 수정하지 않습니다.
