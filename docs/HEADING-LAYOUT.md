# 메인 제목 크기와 줄바꿈 정리

- 겹쳐 있던 제목 크기 규칙 9개를 공통 규칙으로 정리했다.
- PC 제목 최대 48px, 일본어 최대 42px. 모바일은 화면 폭에 따라 일반 언어 30~42px, 일본어 24~36px.
- 일본어 제목의 의미 단위 두 줄을 유지해 「を」 한 글자만 다음 줄에 남지 않게 했다.
- 한국어는 단어를 유지하고 라틴 문자 언어는 줄의 길이를 균형 있게 나눈다. 아주 좁은 화면에서는 긴 단어도 넘치지 않게 한다.
- 제목 문구, H1 구조, 검색 제목·설명, 국가·언어·프로필 예시·도구는 변경하지 않는다.
- 우측 장식의 배경 효과가 태블릿에서 가로 스크롤을 만들지 않도록 범위를 조정했다.
- 정적 파일 배포이며 Nginx·CRM·DB·단축링크 서비스·인증서를 수정하거나 재시작하지 않는다. CRM 로그인 응답을 배포 전후 읽기 전용으로 검사한다.
